# Notes for agents

Read `BRAND.md` before any visual work.

`tokens.css` is the only file that may hold a raw colour value. Run `node scripts/check-tokens.mjs` when you change the look of a page. Do not link `tokens.css` or `components.css` from an existing page until a later phase says so. `/styleguide` is the reference. It is noindex, and it does not load Tag Manager.
